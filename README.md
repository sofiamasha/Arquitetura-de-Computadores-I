# 💻✨ Arquitetura de Computadores I

📚 Repositório dedicado aos estudos, resumos e atividades da disciplina de Arquitetura de Computadores I — PUC Minas

---

## 🌸 Sobre a disciplina

Arquitetura de Computadores I aprofunda os conceitos introduzidos em Introdução à Computação, explorando de forma mais detalhada como um computador funciona internamente.

É uma disciplina com forte base teórica, focada na compreensão dos componentes e da organização dos sistemas computacionais.

---

## 🧠 O que você aprende aqui

🔍 Fundamentos da arquitetura:

* Organização básica de computadores
* Funcionamento da CPU
* Memória (hierarquia, cache, RAM)
* Entrada e saída (I/O)

⚙️ Conceitos importantes:

* Representação de dados (binário, hexadecimal)
* Ciclo de instrução
* Linguagem de máquina e assembly (introdução)
* Desempenho e eficiência
